# Attendance Management System

A full-stack Attendance Management System built for **teachers, tutors, gym instructors, and other hourly professionals** to efficiently manage clients, attendance records, pricing plans, and payment status from a single dashboard.

## 🚀 Features

- 🔐 Secure Authentication
- 👥 Client/Student Management
- 📅 Attendance Tracking
- 💰 Flexible Pricing Setup
  - Hourly
  - Per Session
  - Monthly
- 💳 Payment Tracking
  - Paid
  - Pending
  - Partial

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Cshraddha153/Attendance-Management-System.git

cd Attendance-Management-System
```

### Backend Setup

```bash
cd Backend

npm install
```

Create a `.env` file:

```env
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

Run the backend:

```bash
npm run dev
```

---

### Frontend Setup

```bash
cd Frontend

npm install

npm run dev
```
